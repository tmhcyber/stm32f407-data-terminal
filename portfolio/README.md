# 项目作品集

[五页 PDF](project-portfolio.pdf) · [首页预览](preview.png)

五页作品集展示通信规则设计、CAN协议与队列逻辑、RS485时间下溢独立诊断、实板通信结果，以及FreeRTOS最新值邮箱与个人贡献。

阅读重点：一小时36000/36000次RS485应答、1800/1800次CAN应用应答，以及从波形和计数推导时间交错根因的诊断过程。测试配置、原始日志和固件版本均有对应入口。

作品集基于2026-10-22通信记录与2026-10-04 FreeRTOS记录，文案于2026-11-15更新。最新Modbus成果见[项目首页](../README.md#modbus-rtu-实板成果2026-11-15)和[实板记录](../evidence/modbus/README.md)。

`project-portfolio.html`内嵌同一份PDF，便于浏览和下载。

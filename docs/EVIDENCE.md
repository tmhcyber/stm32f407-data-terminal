## 软件检查与板测分开

- RS485 模块历史生产 C 检查使用假 BSP，历史 ARMCC 全量构建0错误0警告，最终初始化修正版板测为单轮冒烟。
- CAN 软件队列顺序和不覆盖另由主机实际 C 测试覆盖，板测四帧同载荷不能扩展到顺序结论。
- RTOS v4 历史 Clang 实际任务 / SHT30 主机 C 测试5组输出，Python18项及2子测试，ARMCC全量构建0错误0警告；主机假队列不能替代内核调度器。
- Fault 未定义指令 UsageFault /跨NRST记录 /一次消费，以及 IWDG 健康输入注入来自模块历史验收；没有在本次作品集制作中重测。

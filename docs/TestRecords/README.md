# 测试记录与复核入口

本目录提供统一格式的通信、采集和主机检查记录，包含配置、实际规模、完整日志、执行脚本快照及SHA256核验。

- [通信测试总览](2026-10-22_communication_01/README.md)：RS4851000轮及一小时36000轮，CAN1 Hz 1800次。
- [测试方法与结果](2026-10-22_communication_01/RESULTS.md)：时间预算、并行负载、统计口径和采集连续性。
- [主机侧自动化检查](2026-10-22_host_01/README.md)：Python检查、生产C断言及CAN场景分类记录。
- [记录格式](TEMPLATE.md)：日期、commit、开发板、适配器、波特率、脚本版本和结果字段。

## 可追溯设计

测试记录以“Git基线 + 固件AXF SHA256 + 执行脚本SHA256”标识版本。通信日志保存逐轮请求/响应、UTC与单调时间；汇总计数与原始数据独立复核。gzip仅压缩原文，解压后可按记录校验正文哈希。

原始二进制UART配套记录头和元数据，分块日志可逐字节重建原始流。主机检查使用专门记录，项目规模与统计单位一目了然。

Git历史管理归档与文档更新，完整执行快照保存在各记录的scripts目录。原工程归档入口为 `Tools/archive_communication_records.py`；展示仓库的脚本快照用于审阅对应执行版本。

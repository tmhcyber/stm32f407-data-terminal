# 个人贡献和协作说明

项目为个人学习型原型，各模块参与程度不同。

| 模块 | 陶铭浩的代表性参与 | Codex 辅助与限制 |
| --- | --- | --- |
| 采集 / 快照 / PC | 参与采集联调；主导 PC 超长坏行丢弃 /重同步测试取舍 | 完整实现及工具集成有辅助，不统一声称独立驱动开发 |
| RS485 | 主导参数、状态表、边界验收与板测；独立推导旧now与新ISR时间下溢 | 完整BSP、应用、PC工具、测试与修复由Codex实现和集成 |
| CAN | 指导审查下编写请求校验、5字节编码及环形队列入出队逻辑，操作实板 | HAL、ISR、临界区、恢复与集成有Codex辅助；非独立完整CAN栈 |
| Fault | 主导记录接受 /启动消费规则，结合现场辅助定位UsageFault | 完整异常记录与集成有辅助；NRST保留非掉电持久化 |
| IWDG | 主导ALLOW/HOLD/LATCH、健康门控、预算与验收选择 | 完整代码集成有辅助；传感器离线可降级喂狗，非每个传感器错误都复位 |
| FreeRTOS | 根据显示业务选择最新值；指导下编写采集、换算、覆盖及失败记录 | 适配、诊断集成、构建下载与实验取证由Codex完成；独立完整复现待验证 |

面试以具体设计、代码和观察为依据。工程存在实现 /测试证据不等于个人独立掌握；测试数量不代表独立编码量。个人代码练习保留源码中的原注释，协助集成的保护逻辑不归为个人独立设计。
